What a counted cross-stitch PDF includes

Each single chart is one instant-download PDF. The pictures lower on this page are watermarked samples. The full PDF, without the SAMPLE mark, is delivered after purchase. There is no pattern file sitting on this website for you to save.

  • A symbol chart in color

    The design on a grid, with symbols and a key so each square maps to a floss color.

  • A black-and-white chart

    The same count, drawn so it still reads if you print in black and white.

  • A DMC floss key

    Cotton floss numbers, color names, and a stitch count for each color. The numbers name the colors.

  • A stitching guide

    How the chart is meant to be worked. The floss key notes skein estimates for 14-count Aida.

Supplies to have ready

Buy these when you are ready to stitch. This page does not link to a shop. The PDF names the floss.

  • Aida cloth. The floss key’s skein note is written for 14-count.
  • A hoop large enough for the stitched area, with a margin of unworked cloth.
  • Six-strand cotton floss in the DMC numbers the key lists, and a tapestry needle.
  • Small sharp scissors and a way to mark your place on the chart.
